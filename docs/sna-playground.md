## 来源、身份与重现

输入资料：

1. `final.xlsx`：Sheet1 的 26×26 加权矩阵，行列名称顺序逐项核对一致；“吸引力”表可用于辅助核对。
2. `2022结果.xlsx`：完整命名的 CONCOR 分组、关系数量、核心成员、度、结构洞、专门的中介中心性表、中间人原始计数及 QAP 输出。
3. `第八组-李想.docx`：研究方法、指标含义、结论与来源差异背景，含嵌入的图表。公式依正文含义与用户明确提供的公式实现，不推测缺失的原始指标。
4. `社会网络分析.gephi`：读取工作区与存储结构；包含 `final_binary`、`final_binary_median`、`图书馆微博(1)` 等工作区。graphstore 的二进制节点坐标未能可靠解码，不把其他工作区当作当前网络。

`dev/build-sna-data.py` 使用 openpyxl 读取 Excel，核对来源名称、计数、各表数据映射，并输出 `lab/sna/data.json`。输出保留四份源文件 SHA-256、精确矩阵、列均值、二值矩阵、各节点已有指标、原表与复核值、缺失字段及审计记录。原始 Word、学号与完整原始压缩工程不加入网站。

原矩阵名称为身份依据。`武汉城市学院` 等别名映射到 `武汉科技大学城市学院（武汉城市学院）` 的同一 ID，禁止重复生成高校。英文为导航展示译名，中文原始名称与数字 ID 保留在 JSON；数据计算只用 ID。明确区分 `PCA_i`（人均馆舍面积）与 `LS_i`（主成分分析后的综合规模得分）。

用原文件重新生成：

```sh
python -B dev/build-sna-data.py \
  --matrix /path/to/final.xlsx \
  --results /path/to/2022结果.xlsx \
  --report /path/to/第八组-李想.docx \
  --gephi /path/to/社会网络分析.gephi
node dev/build-lab-pages.js
node dev/build-vercel.js
```

Python 仅用于预处理；Vercel/静态页面运行不需要 Python 或新增依赖。四份原文件在本次环境下重复生成的 JSON 与已保存文件逐字节一致，没有时间戳或随机布局引入的不稳定结果。

## 数值核验

- 加权矩阵为 26×26，非负有限值，行列身份一致，对角线全零。
- 每列均值为完整列和 / 26，包括对角零。以 `i≠j && Fij≥mean(column j)` 二值化，去除自环。
- 26 个真实高校，269 条有向边，整体密度 `269/(26×25)=0.4138461538`。
- 核心成员从原表 Core 行提取，共 11 个，内部 108/110，密度 `0.9818181818`；保存的拟合相关系数为 0.9723。
- 核心→边缘 159/165，边缘→核心 0/165，跨两方向合计 159/330；边缘内部 2/210。
- 从同一二值矩阵独立核对 15 个强连通分量、1 个弱连通分量；最大强连通分量成员恰与记录核心一致。不能把两种方法等同或把 15 解释为弱意义的互不连通子图。
- 二值入/出度逐节点匹配“度”表；加权入/出强度与 `degree` 表的三位小数结果匹配，容差 0.00051。主页面强度用完整 F 求和，不把加权值当二值度数。
- 结构洞与专门的 UCINET 中介中心性表按名称映射，保留其原始精度和软件口径，不把其他表中的同名列混入。

CONCOR 完整分组：10 / 1 / 9 / 6。16 个有向块关系数量逐格复核一致：

| 发出→接收 | 1 | 2 | 3 | 4 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 90 | 10 | 90 | 60 |
| 2 | 8 | 0 | 9 | 0 |
| 3 | 0 | 0 | 2 | 0 |
| 4 | 0 | 0 | 0 | 0 |

每个块的密度分母为 `size_a×size_b`，同块再扣除自环。单节点块内部可能边为零，密度未定义，不误报为 0% 的实测密度。

## 五个模块

1. **修正引力模型**：完整分式/四次方根与三个可点击解释部分。手机分层排版。双向读取真实 Fij/Fji；26×26 表内滚动、单格精确值与该列均值、二值判断；支持方向键。构建演示依次展示列均值、阈值去自环、真实网络。没有原始资源/交通指标滑块或重算假实验。
2. **核心—边缘**：完整/核心/跨核心边缘/边缘四种筛选；真实计数与密度联动。点击节点或高校选择框联动身份与入/出/双向邻居。当前焦点在稀疏子网中没有边时，保留实际边清晰可见。拟合与 SCC 解释分开。
3. **CONCOR**：高校分组、4×4 密度、四板块聚合三种视图，复用相同有向网络组件。矩阵点击高亮对应 a→b，分别展示数量、可能边、复核密度、原表密度、原表理想关系与按报告密度标准复核的判定。聚合箭头数量为真实边数，自环表示块内关系而非高校自环。
4. **网络显微镜**：真实邻居局部网络与已保存结构洞指标。另有五种中间人概念图，明确标示为概念；若有已保存计数且从 B 与 CONCOR 组别复核吻合，可展示真实开放有向两步路径实例。起点→终点无直接边，角色由三个群体归属判定。25 个存在的原始计数行全部匹配；缺失节点不显示伪造的零。
5. **QAP**：保存的相关系数与标准化回归系数分别绘制，辅以原始非标准化系数、P 值、R²、观测值与置换次数。同步行列的动画使用真实前四高校子矩阵，仅说明置换机制，不运行新的 QAP、不生成分布、不改变归档统计。

所有网络共享 `network.js`，节点身份始终由原始矩阵 ID 决定；位置由真实二值网络的确定性力导向布局生成，CONCOR 视图可平滑转为确定分组布局。焦点使用出边/入边/互惠颜色，辅以箭头与文字。支持主题、键盘节点、减少动态、后台停止构建演示、数据异常禁用与重试。旧 `#network` 对应核心章节，语言链接保留当前研究章节。

## 不一致与保守处理

- **板块 3 密度**：`块模型!D11` 为 0.28，计数为 2、节点为 9，实际复核 `2/72≈0.02778`。两个值并列保留，未静默改写原表。
- **板块 2→1 理想关系**：原理想表为 0，但密度 0.8 高于全网约 0.41385，按报告文字标准应为 1。保留原表与规则复核结果，不宣称已有唯一修正像矩阵。
- **板块 4 比例**：零发出边时相关比例 0/0 未定义；不把原表外部比例 1 当作可计算结果。
- **角色判定**：角色逐字沿用“首属人、经纪人、孤立者、谄媚人”。展示明确分母的实际比例，但原定性阈值未完整保存，不擅自重分类或等同于个体中间人类型。
- **CONCOR 简写成员表**：板块 4 简写表漏列武汉工程大学、武汉体育学院。采用相互一致的完整名称表 `B32:C57`、列分类 `B26:AA26`，且能复核关系数量矩阵。
- **中间人缺行**：原始计数区域 `中间人!A2:G27` 仅有 25 所高校，缺武汉软件工程职业学院。后面的预期值、相对值不替代原始计数。独立网络核验虽可得零，也不填作“Excel 已保存的 0”。
- **距离回归 P**：`回归性分析!H5=0.073663`、`O9=0.083663`，都展示为未核实的两个记录，不选其中一个作为唯一精确值。
- **QAP 解释**：相关精确值合作意愿 0.765208、距离 −0.091991，保存显著性均为 0.0002；回归 R²=0.6686。回归仅列出两项系数，说明文字却提到四变量，不补造其他变量。原相关表的 N Obs 是归档输出字段，不能误称为 26×25 的观测对数；回归单独保存 Obs=650、Perms=2000。
- **时间与因果**：不沿用单期资料证明距离影响“随时间减弱”的说法，也不从相关、吸引力或网络位置断言实际合作频次、流量或因果效应。
- **Gephi**：未恢复可验证的原布局坐标，采用已说明的确定性力导向替代；不引入大型 Gephi/Java 运行时。
