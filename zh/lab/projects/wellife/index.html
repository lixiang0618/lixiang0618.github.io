工作原理 · 方法与来源

识别为模拟：食物使用预设图片查表；运动从合成信号计算特征、规则 Logits 和真实 Softmax。营养来自用户提供的示例，MET 为标明的教学假设。未运行训练视觉/CNN 模型、AI API 或后端。

摄入与供能氧化估算分别汇总，不估算糖或水的运动使用量。没有保存供能比例的旧运动记录保持未知。本地记录仅保存在当前浏览器。

运动信号生成

固定种子的分段位置轨迹 → 数值微分得到速度 → 再微分得到加速度，并加入重力与少量传感器噪声。步行使用非对称步态模板；俯卧撑与深蹲的深度、节奏和停顿不同；跑步和蛙跳包含抛体腾空与落地；静坐为缓慢、非周期姿态漂移。

世界坐标信号是教学近似，不是真实可穿戴 IMU 测量。

MET 能量估算

Egross=MET×3.5×W×t200Eactive=(MET−1)×3.5×W×t200

W 单位 kg，t 单位分钟，E 单位 kcal。群体标准估算会受体能、动作方式与个人代谢影响；各运动旁列明参考条目和代理映射。

单独看待供能假设

rC+rF+rP=1

C = Egross rC / 4
F = Egross rF / 9
P = Egross rP / 4

仅示意克数，不是实测底物氧化、糖消耗或体液平衡。
