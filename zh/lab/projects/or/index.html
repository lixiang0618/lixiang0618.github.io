04

模型与方法

论文模型、复现约定与网页展示方式是三个不同层面。

系统与运动规则

SP-AS/RS 将垂直与水平平台分离：每架一台 VP，每层一台 HP。DC 周期存入一件、取出一件；存完才揭示取货位置，交接时间为零。

Xᵢ = xᵢ/vₕ, Yᵢ = yᵢ/vᵥ; Tₛ = X₁ + Y₁

同层: Tᵣ = |X₁ − X₂| + X₂ + Y₁

异层: Tᵣ = max(|Y₁ − Y₂|, 2X₂) + Y₂

T = Tₛ + Tᵣ

异层 VP 与取货 HP 同时开始，较快的一方等待较慢的一方。送达 I/O 即停止计时，不额外等待存储 HP 空载回位。每个独立 DC 重置设备初态。

解析公式 · 论文式（16）

L = mw, H = nh, tₕ = L/vₕ, b = (H/vᵥ)/tₕ; n = 层数.

E[T] = tₕ · F(b,n)

0 < b ≤ 2: F = 3/2 − 1/(6n) + b + (n−1)b²/(24n)

b > 2: F = 1/2 + 5/(6n) + (4n−1)b/(3n) + (4n−4)/(3nb) − (2n−2)/(3nb²)

连续理论面采用 H=nh，默认离散最高层却位于 (n−1)h。公式保留同层概率 1/n，但异层高度差使用连续近似；计算时不舍入形状因子。

Monte Carlo、Gap 与置信区间

Êₙ = (1/N) Σ Tᵢ; s² = Σ(Tᵢ−Êₙ)²/(N−1)

SE = s/√N; CI₉₅ = Êₙ ± 1.959963984540054 · SE

Absolute Gap = |Êₙ − E[T]|

Relative Gap = 100 · |Êₙ − E[T]|/|E[T]| %

理论分母为零时相对差值未定义。区间沿用 Python 的正态近似，描述模拟总体均值的抽样不确定性，而非公式的不确定性；早期小样本区间可能不可靠。检查点为同一条序列的前缀，不是独立重复实验。稳定差值可能合理，解析线不必落在区间内。

浏览器使用 Mulberry32 与无偏整数拒绝抽样，并非 NumPy PCG64；相同种子不代表 Python/JavaScript 序列相同。数值对照使用完全相同的任务序列。

假设、坐标与限制

存取层列独立、均匀、有放回抽样，允许同一货位。没有库存、调度、排队、加减速、非零交接时间、额外深度运动、其他停驻策略、单指令比较或回到空闲点的延迟。

默认 tier1_origin 是复现约定，并非论文公开源码。其他模式用于敏感性分析。模拟完整矩形货架，不为匹配发表表格中不一致的容量标注而删格。较小 Gap 或 b=1 均不证明仓库最优。

SVG 深度、第二排货架和重播节奏均为教学展示选择；模型坐标可能位于货位参考边界。图形最多显示 12 个层组、20 个列组，实际抽样点仍按比例定位。
