Run Details

Methodology / Model Details
DC / SC animation timing

DC timing follows the supplied model: storage completes before retrieval begins; different-tier VP movement and retrieval HP round trip start together. The animation shares one linear physical clock, uniformly mapped to an 18-second presentation.

SC shows two standard I/O-return commands. After storing, VP returns to I/O while the empty storage HP resets independently. A new retrieval command releases VP and the retrieval HP; on the same tier, HP must finish its reset before retrieving. Both must meet at the handoff before final delivery. This is a mechanism reference, not an additional Monte Carlo or analytical result from the paper.

System & movement rules

SP-AS/RS separates vertical and horizontal platforms: one VP per rack and one HP per tier. A dual-command cycle stores one item and retrieves another. Retrieval is revealed only after storage. Transfers take zero time.

Xᵢ = xᵢ/vₕ, Yᵢ = yᵢ/vᵥ; Tₛ = X₁ + Y₁

Same tier: Tᵣ = |X₁ − X₂| + X₂ + Y₁

Different tiers: Tᵣ = max(|Y₁ − Y₂|, 2X₂) + Y₂

T = Tₛ + Tᵣ

Different-tier VP and retrieval HP start together. The faster waits for the slower. Timing stops on delivery to I/O; storage HP reset adds no delay. Each independently sampled cycle resets the equipment.

Analytical formula · paper Eq. (16)

L = mw, H = nh, tₕ = L/vₕ, b = (H/vᵥ)/tₕ; n = tiers.

E[T] = tₕ · F(b,n)

0 < b ≤ 2: F = 3/2 − 1/(6n) + b + (n−1)b²/(24n)

b > 2: F = 1/2 + 5/(6n) + (4n−1)b/(3n) + (4n−4)/(3nb) − (2n−2)/(3nb²)

Continuous face dimensions use H = nh even when the default discrete top tier lies at (n−1)h. The formula retains same-tier probability 1/n but approximates different-tier height differences continuously. Shape factors are not rounded before computation.

Monte Carlo, Gap & confidence intervals

Êₙ = (1/N) Σ Tᵢ; s² = Σ(Tᵢ−Êₙ)²/(N−1)

SE = s/√N; CI₉₅ = Êₙ ± 1.959963984540054 · SE

Absolute Gap = |Êₙ − E[T]|

Relative Gap = 100 · |Êₙ − E[T]|/|E[T]| %

A zero theory denominator makes relative gap undefined. Intervals use the same normal approximation as Python and describe uncertainty in the simulation population mean, not the formula. Early small-sample intervals can be unreliable. Checkpoints are prefixes of one run, not independent replications. A persistent gap can be legitimate; the analytical line need not fall inside the interval.

Browser sampling uses Mulberry32 with unbiased integer rejection, not NumPy PCG64. Equal seeds do not imply equal Python/JavaScript sequences. Numerical parity is tested on identical supplied task sequences.

Assumptions, coordinates & limitations

Storage/retrieval tiers and bays are independent, uniform and sampled with replacement; the same cell is allowed. There is no inventory, scheduling, queueing, acceleration, nonzero transfer time, extra depth travel, additional dwell policy, SC numerical comparison or return-to-idle delay.

The default tier1_origin coordinate convention is a reproduction choice, not published source code. Other supported modes test sensitivity. Complete rectangular racks are modeled without removing cells to match inconsistent published capacity labels. Neither a small Gap nor b=1 proves an optimal warehouse.

SVG depth, the second rack and replay cadence are teaching choices. Model coordinates may lie on compartment reference boundaries. Drawing uses up to 12 tier groups and 20 bay groups; exact sampled positions remain proportional.
